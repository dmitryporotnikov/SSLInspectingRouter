# Localization

The dashboard is localized. A language picker is on the login screen and the top bar. Available languages are discovered from the embedded locale JSON files in `internal/dashboard/frontend/locales/`, so the dropdown is populated automatically from whichever language files you have shipped.

To add a new language, see the contributor guide:

→ [Localization Contributing Guide](../LOCALIZATION_CONTRIBUTING.md)

The existing locale files are at `internal/dashboard/frontend/locales/`. The current set includes English (`en`), German (`ge`), Hindi (`hi`), and Russian (`ru`).
